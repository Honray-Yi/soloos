# Fictional examples / 虚构示例

All data in this directory is synthetic. These files demonstrate behavior, not real
company results or recommended financial benchmarks.

| File | Purpose |
| --- | --- |
| [management-business.json](management-business.json) | Extended v1 input: consulting company, operational records and measurements |
| [executive-report-v1.md](executive-report-v1.md) | Human-readable v1 weekly report |
| [management-review.json](management-review.json) | Eight-department structured review |
| [cash-forecast.json](cash-forecast.json) | Explicit constant-rate cash scenario |
| [decision-outcome.json](decision-outcome.json) | Observation compared with a user-selected decision target |
| [weekly-report.md](weekly-report.md) | Historical Phase 1 example, retained for reference |
| [marketing-decision.json](marketing-decision.json) | Historical proposal used by the outcome example; not executed |

The baseline demo input ships with the skill at
[demo-business.json](../.agents/skills/soloos/assets/demo-business.json).
Output timestamps and source versions identify when each artifact was generated;
old examples are not silently rewritten as newly verified decisions.

For the independent copy-and-paste edition, use
[the prompt-only fictional case](../prompt-edition/examples/quick-start.txt).
